# Code Counter

Библиотека для подсчета строк кода в проекте с учетом `.gitignore` и анализом вклада разработчиков.

## Возможности

- Подсчет общего количества строк кода
- Разбивка по типам файлов (расширениям)  
- Анализ вклада каждого разработчика через git blame
- Учет `.gitignore` (автоматическое игнорирование)
- CLI и Python API
- Поддержка 30+ языков программирования

## Установка

```bash
pip install code-counter-ntwusr
```

## Использование

### CLI

```bash
# Анализ текущей директории
code-counter

# Анализ конкретного проекта
code-counter /path/to/project

# С показом топ-10 файлов
code-counter --files
```


## Требования

- Python 3.12+
- Git (для анализа авторства)
